# abco-dismantling-automation
Automated tools and tracking systems for dismantling operations at Abco Fridley Auto Parts.

## Google Sheets Integration

The `scripts/inventoryImprovements.gs` file contains a Google Apps Script used to configure the Master Equipment_Inventory spreadsheet. It sets dashboard formulas, applies data validation, prepares a maintenance form link for QR codes, and adds an efficiency audit sheet. Deploy this script inside the Google Sheets environment to apply the enhancements described in the project documentation.
